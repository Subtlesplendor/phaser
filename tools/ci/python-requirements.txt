# Four packages were approved -- matplotlib, nbclient, nbformat, and the
# ipykernel they need to start a kernel. This file is the complete set those
# four resolve to, pinned to exact versions and hashed. It is the Python
# counterpart of build.zig.zon, and an unpinned or unhashed entry is a defect.
#
# Resolved for Linux x86-64 and CPython 3.12, which is the only platform the
# notebook tier runs on; decision 0015 records why. The hashes are of the
# wheels for that platform, so this file does not install elsewhere. A
# contributor running the notebook locally installs the same four packages
# unpinned -- reproducibility is a property this tier needs and a laptop does
# not.
#
# Install with both flags, which is what .github/workflows/ci.yml does:
#
#   pip install --require-hashes --no-deps -r tools/ci/python-requirements.txt
#
# --require-hashes makes an unpinned entry an error rather than a resolution;
# --no-deps makes this list exhaustive rather than a starting point.
#
# REGENERATING. Resolve the four direct requirements for the target platform
# and hash the resulting wheels:
#
#   pip download --only-binary=:all: \
#     --platform manylinux2014_x86_64 --platform manylinux_2_28_x86_64 \
#     --python-version 3.12 --implementation cp --abi cp312 \
#     --dest wheels matplotlib nbclient nbformat ipykernel
#
# Both platform tags are required and the wider one is not optional. pip
# selects the newest release having a wheel for a tag it was given, and
# silently takes an older release otherwise. Resolving with manylinux2014
# alone held four packages back, one of them Pillow, past a release fixing
# thirteen advisories -- newer Pillow ships manylinux_2_28 wheels only. The
# runner is Ubuntu 24.04 with glibc 2.39, so it installs either.
#
# Adding, removing, or moving an entry is a dependency change under AGENTS.md
# and needs its own approval.
