# Real scalar phi4 model

This is the public Milestone 1 source-model example for

\[
V_0(\phi)=\Omega+\frac{m^2}{2}\phi^2+\frac{\lambda}{4!}\phi^4.
\]

Run `zig build examples` to parse, validate, fingerprint, and inspect it through
the public experimental Zig API. `inspection.txt` is the reviewed deterministic
output. The same model is referenced by the scalar phi4 conformance manifest.
